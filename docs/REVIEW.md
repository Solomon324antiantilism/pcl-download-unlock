# 1.0.1 代码审查与验证

审查范围：补丁引擎、文件替换及还原、进程检查、目录发现、历史记录读取、界面完成状态、依赖与公开发布内容。

## 已修复的问题

| 问题 | 影响 | 修复与证据 |
|---|---|---|
| 按进程名筛选会漏掉改名的启动器 | 运行状态检查不能满足“目标 PCL 已关闭”的要求 | 查询可访问进程的实际映像路径；对疑似目标但无法检查的进程保守停止。测试覆盖原名称、改名和 x86 查询 x64 进程。 |
| 历史记录直接反序列化到强类型 | 损坏的 `Schema` 可抛出通用转换异常，阻断检查，甚至让完成后的界面刷新误报失败 | 使用字典解析并显式验证字段类型，忽略过大/损坏/链接记录；新增错误类型历史用例。另将操作成功与后续刷新失败分开处理。 |
| 备份在首次校验后仍可能变化 | 替换目标时，相邻备份可能已经损坏 | 替换前重新校验并持有只读共享句柄，直到替换完成；用准备完成后篡改备份的测试验证目标保持原样。 |
| Downloads 路径固定拼接用户目录 | 可能漏掉迁移过的下载目录 | 使用 Windows Known Folder API 查询当前配置的 Downloads；失败时回退默认路径。 |
| 每条方法/字段比较都重新搜索声明类型 | 校验有不必要的重复遍历 | 缓存用于比较的固定名称，保留完整比较和已验证产物哈希。 |

补丁范围仍为一个明确原始 SHA256 的 PCL 2.99.0.0；没有扩大到未知构建或整合包安装。

## 测试结果

- 本地完整隔离回归：**22 项通过**。输入原始程序只读，所有修改发生在测试副本。
- 无 PCL 文件的公开冒烟检查：**10 项通过**，覆盖内嵌依赖、异常输入、损坏记录、未知文件保护、发现/取消、多候选界面和改名进程。
- 单文件 EXE 的 PE 检查：x86、Windows GUI、32-bit required、.NET Framework 4.8、asInvoker。
- 1.0.0 已完成图形界面的隔离副本修改/还原测试；1.0.1 另外执行构建、上述回归和实例化窗口的多候选选择检查。不要把旧版界面验证写成对新版全部交互的实测。
- 未逐一实测其他 Windows 版本、x86 实体系统或 ARM64 设备；未通过真实 PCL 验证版本列表和实际 Minecraft 下载。

## 公开发布检查

- 只包含工具源码、说明、测试、构建配置、许可及固定来源的 dnlib DLL。
- 不提交测试副本、原始/修改后的 PCL、用户操作记录、账号数据、绝对个人路径或凭据。
- dnlib 4.5.0 的 SHA256 和完整 MIT 声明保留，程序 About 内也包含声明。
- CI 权限仅 `contents: read`，依赖 Actions 固定到已核对的提交 SHA；不自动发布 Release，不持久保存检出凭据。

这次审查降低了已识别问题的风险，不代表对任意未知构建或所有外部文件竞争提供绝对保证。目标哈希和进程状态在替换前再次核对；替换仍依赖本机 Windows 文件系统行为。
